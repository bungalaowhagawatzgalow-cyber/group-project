[![Esolang](https://img.shields.io/badge/Esolang-Joke-orange.svg)](https://esolangs.org/wiki/Group_Project)

A joke esoteric programming language where programs are group chat transcripts.

## The Cast

| User | Role |
|------|------|
| `@me` | Variables, arithmetic, print, functions, if/else. Unrecognized lines are ignored. |
| `@slacker` | Fixed list of non-answers. No mechanical purpose. |
| `@deadline` | Controls loops. |
| `@prof` | Final line. Receives output. |
| `@parent` | Debug and panic button. |

## Requirements

- [Python](https://www.python.org/downloads/) 3.6+
- No external dependencies
